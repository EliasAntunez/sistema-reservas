¿Qué son las configuraciones?

Las configuraciones de horario son plantillas reutilizables que definen los días y horarios de apertura.

Ejemplos de uso:
  • Horario Por Defecto: Horario base para todo el complejo (Lun-Dom 15:00-00:00)
  • Horario Personalizado para Canchas: Horario específico para canchas (Lun-Dom 18:00-00:00)
  • Horario Personalizado para Salones: Horario específico para salones (Lun-Dom 15:00-21:00)
  • Horario Especial: Para eventos o temporadas (Verano, Invierno)
Próximo paso

Después de crear la configuración, podrás agregar los rangos horarios (días y horas específicas) y asignarla como Por Defecto o Personalizada.

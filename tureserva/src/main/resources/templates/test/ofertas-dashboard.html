📋 Cómo Probar el Flujo Completo

  1. Crear una reserva con seña y política de cancelación (ej: 48 horas de anticipación)
  2. Modificar temporalmente la fecha de la reserva en la BD para que esté dentro del plazo de cancelación tardía
  3. Ejecutar "Enviar Avisos" desde este panel para enviar el email proactivo
  4. Cancelar la reserva desde el panel de usuario → Se generará automáticamente una Oferta Flash
  5. Ver la oferta usando el token desde la sección "Ofertas Flash Disponibles"
  6. Reclamar la oferta con otro usuario → Se crea nueva reserva y se acredita 50% al cliente original
  7. Verificar emails enviados (confirmación al cliente original y nuevo cliente)
  8. Verificar cuenta corriente del cliente original (debe tener crédito de 50%)
